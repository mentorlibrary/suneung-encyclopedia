# 수능 연대기 백과

고등학교 1학년에게 설명하듯 쓴 대학수학능력시험(수능)의 역사 백과사전이에요. 1994~2026학년도의 학년도별 만점자 수, 난이도, 별명을 검은 펜 라인아트 애니메이션과 함께 담았어요.

- 웹에서 보기: GitHub Pages를 켜면 `https://mentorlibrary.github.io/suneung-encyclopedia/`
- 파일로 보기: `index.html`을 내려받아 브라우저로 열기

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `index.html` | 최신 백과사전 |
| `versions/` | 버전별 페이지 (v1 = 첫 버전) |
| `debate/` | 5색 팀 토론 기록 (라운드별 점수와 의견) |
| `workflows/` | 페이지를 만든 멀티 에이전트 워크플로우 스크립트 |

## 만든 팀 (5색 페르소나)

| 색 | 역할 |
|---|---|
| ⚫ BLACK | 저자. 페이지를 직접 쓰고 고쳐요 |
| 🔴 RED | 반대 의견을 내요 |
| 🔵 BLUE | 좋은 점을 찾아 지켜요 |
| 🟡 YELLOW | 아이디어를 내요 |
| 🟣 PURPLE | 색다른 아이디어를 적용해요 |

블랙이 고치면 나머지 넷이 10점 만점으로 채점하고, 평균 9.5점이 될 때까지 토론을 반복해요.

## 주의

만점자 수와 난이도는 언론 보도 등을 바탕으로 정리한 값이라 일부는 추정치예요. 정확한 숫자는 한국교육과정평가원 자료로 확인하세요.
